# Perfil de estilo

Use quando o usuário anexar votos seus e pedir o perfil de estilo.

Leia de 3 a 6 votos. Se vierem menos de 3 ou mais de 6, peça esse intervalo e não complete com voto de outra pessoa. Este plugin não traz voto de exemplo.

Do que for forma, registre estrutura, formato da ementa, frases feitas, fórmula de honorários e função dos parágrafos.

Diga ao usuário para salvar o perfil como arquivo de Project com o nome `perfil-estilo.md`.

O perfil governa só a forma. Nunca extrair fatos de exemplos de outros casos.

Não copie nome, número de processo, diagnóstico ou resultado desses votos para outro processo.
