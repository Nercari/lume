# Lume JEF

Lume JEF é um plugin do ChatGPT para quem trabalha com recursos nos Juizados Especiais Federais (JEF/TRF1). Ele lê o processo reunido pelo assistente Lume (a aba do caso ou as partes anexadas), entrega o relatório preliminar e redige a minuta de voto, ementa e dispositivo para conferência de um profissional habilitado.

- Funciona só com skills. Não tem servidor, não entra no PJe e não coleta dados.
- O formato padrão é neutro. Você pode criar seu próprio perfil de estilo a partir de 3 a 6 votos seus.
- A forma de levar o processo ao chat (assistente Lume, painel lateral do ChatGPT no PJe ou anexo) está em definição.

Lume JEF is a ChatGPT plugin for staff and judges working on appeals at Brazil's Federal Small Claims Courts (JEF/TRF1). It reads a case gathered in the Lume case format, writes the preliminary report and drafts the ruling for a qualified professional to review. Skills only: no server, no PJe access and no data collection.
